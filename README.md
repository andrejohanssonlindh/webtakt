# Webtakt

A browser-based step sequencer and synthesizer — vanilla JavaScript, no build
step. Open `index.html` over a local HTTP server (e.g. `python3 -m http.server`)
and play.

See [DESIGN.md](DESIGN.md) for the architecture overview.
